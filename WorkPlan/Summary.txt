1. Система статов

В проект добавлена базовая runtime-система статов для GuildIdle.

Основные классы:
- Stat
- StatCollection
- StatModifier
- TimedStatEffect
- StatModifierType
- StatTarget

Как работает Stat:
- У стата есть Id.
- Есть текущее значение CurrentValue.
- Есть базовый максимум BaseMaxValue.
- Итоговый максимум MaxValue считается с учетом модификаторов.
- CurrentValue всегда ограничивается диапазоном от 0 до MaxValue.
- Если MaxValue меняется, CurrentValue тоже корректно зажимается в новый диапазон.
- Есть регенерация через Tick(deltaTime), если для стата задан RegenPerSecond.

Модификаторы:
- Flat модификатор добавляет фиксированное значение.
- Percent модификатор добавляет процент от базового значения.
- Модификатор может применяться к Current или Max через StatTarget.
- Несколько модификаторов суммируются.

TimedStatEffect:
- Временный эффект применяется во времени через Tick(deltaTime).
- Эффект может менять Current или Max.
- После окончания Duration эффект удаляется.
- Пример: усталость может постепенно расти во время задачи и перестать расти после завершения эффекта.

StatCollection:
- Хранит набор Stat по id.
- Позволяет добавлять, получать и проверять наличие статов.
- Используется как контейнер для статов героя или другой игровой сущности.

5. Система локализации

Добавлена локализация ru/en/tr.

Основные классы:
- LocalisationModel
- LocalisedText
- LocalisationBuilder

LocalisationModel:
- язык по умолчанию ru;
- поддерживаемые языки: ru, en, tr;
- выбранный язык сохраняется в PlayerPrefs;
- строки загружаются из Resources/Localisation.json;
- если ключ не найден, возвращается сам id.

LocalisedText:
- компонент для TMP_Text;
- берет ключ локализации и обновляет текст при смене языка.

LocalisationBuilder:
- собирает source-файлы из Assets/Configs/Localization/*.json;
- исключает runtime-файл Assets/Configs/Localization/Resources/Localisation.json;
- проверяет дубли и количество языков;
- собирает runtime-файл Resources/Localisation.json.

Локализация заведена для:
- всех базовых статов;
- ресурсов.

6. Редактор конфигов

Добавлено окно:
- Tools/Configs/Config Manager

Возможности:
- просмотр типов конфигов;
- просмотр списка конфигов;
- поиск по Id и DisplayName;
- создание конфига;
- дублирование;
- удаление;
- редактирование public fields через UI Toolkit;
- редактирование вложенных DTO;
- редактирование массивов;
- сохранение JSON;
- переименование файла при изменении Id;
- запуск Validate из окна.

Для ссылочных полей показывается статус:
- OK, если ссылка найдена;
- missing, если ссылка отсутствует.

Для LocalisationNameId и LocalisationDescriptionId добавлены кнопки:
- Create, если поле пустое;
- Edit, если ключ заполнен.

Create:
- генерирует ключ {configId}_name или {configId}_description;
- создает пустую запись локализации в подходящей таблице;
- подставляет ключ в поле;
- помечает конфиг dirty;
- открывает Localization Manager на созданном ключе.

Edit:
- открывает Localization Manager;
- ставит фильтр по ключу;
- выбирает найденную запись.

Таблицы локализации для Config Manager:
- StatConfig -> stats
- ResourceConfig -> resources
- остальные типы используют fallback по IdPrefix.

7. Редактор локализации

Добавлено окно:
- Tools/Configs/Localization Manager

Возможности:
- просмотр source-таблиц локализации;
- создание новых таблиц;
- поиск ключей;
- создание ключа;
- дублирование ключа;
- удаление ключа;
- редактирование Id;
- редактирование ru/en/tr;
- сохранение source JSON;
- пересборка runtime Localisation.json;
- валидация;
- Auto Translate.

Правила ключей:
- ключ не должен быть пустым;
- формат: snake_case;
- разрешены латинские буквы, цифры и подчеркивания;
- ключ должен начинаться с буквы;
- ключ должен быть уникальным среди всех source-таблиц.

Auto Translate:
- берет русский текст из ru;
- переводит в en и tr;
- если en/tr уже заполнены, спрашивает подтверждение перед перезаписью;
- при ошибке сети или парсинга не сохраняет частичный результат.
